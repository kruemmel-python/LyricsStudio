# Sicherheit

Sicherheitsrelevante Probleme bitte nicht zuerst als öffentlichen Issue mit vollständigen technischen Details veröffentlichen.

Nutze stattdessen auf GitHub unter **Security → Advisories → Report a vulnerability** die private Meldemöglichkeit des Repositorys. Beschreibe betroffene Version, Auswirkung, reproduzierbare Schritte und – falls vorhanden – einen Lösungsvorschlag.

Unterstützt wird die jeweils neueste veröffentlichte Version. Songs, Lyrics, lokale Einstellungen, Modellcaches und TATARUS-Lerndaten dürfen einer Meldung nur beigefügt werden, wenn sie frei von privaten oder urheberrechtlich geschützten Inhalten sind.
